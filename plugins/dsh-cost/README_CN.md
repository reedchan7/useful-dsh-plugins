# @reedchan7/dsh-cost

[English](README.md) | 中文

在 DSH composer 下方那一行统计区里显示 DeepSeek API 费用估算：本会话、本轮，以及本机全部项目的今日合计。

## 显示内容

| 位置                  | 内容                                                                                                                                                   |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 统计行 pill           | `¥ Cost ¥9.68`——本机全部项目的今日合计，与自带的轮次、速度、token、缓存命中读数同一行；本会话与本轮的读数在悬停提示和明细面板里                        |
| 明细面板（点击 pill） | 今日按小时柱图、会话合计、缓存命中占比、本轮费用、轮次柱图、按模型拆解、费用构成、当前费率时段与下次调价倒计时、账号级（全设备）区块，以及统计范围说明 |

插件注册在 `conversation.composer.dock`——composer 下方那条自带统计区所在的 ambient 行，因此主题、字号与语言
都跟随界面设置，且不改动自带 UI。该 slot 每个注册条目占一行，而自带统计行没有对外的子 slot，所以本条目把 pill
渲染进自带统计行本身（以 DSH composer 已带的 `data-composer-stats` 标记定位），标记缺失时才退回自己那一行。
与自带 pill 一致，会话还没有产生计费 token 时本条目不显示。

## 安装

```sh
# 从本仓库安装（开发态）
make install

# 或直接装某个 git tag，无需发布到 npm
make install PLUGIN='github:reedchan7/useful-dsh-plugins#v0.1.0'
```

随后重启 `dsh web`，并在浏览器里强制刷新。只重启不会重新构建：`src/` 下的改动要先 `make build`（或
`make reinstall`，构建并重新链接）才会进浏览器。

## 计价模型

- **两份官方价目。** 人民币与美元是两份独立价目，插件不做汇率换算。用哪一份由账号决定，在插件的组合行上
  配置（`- id: dsh-cost` 加 `config: { currency: USD }`）；宿主按它计价，两个路由都回报该币种，浏览器半边
  不做任何假设。
- **峰谷。** 官方高峰时段为北京时间工作日 09:00–12:00 与 14:00–18:00，价格为空闲时段的 2 倍；周末全天
  按空闲价计。面板显示当前时段，并按**你所在时区**给出下次调价的倒计时。
- **价格世代。** 官方在 2026-08-17（引入峰谷）与 2026-09-10（V4.1-Flash 价格）调整过价格。每条用量样本按其
  **自身时间戳**对应的世代计价，因此跨调价的会话仍保留历史费率。
- **未知模型如实标注，不按 0 计费。** 价目表里没有的模型显示为「未计价」并把 pill 变黄——静默显示 0 是一种
  会说谎的费用展示。今日合计也带自己的未计价清单：它覆盖你没有打开过的会话，少算了哪一个必须说出来。
- **费用构成按每次请求计价**，用该请求自己的模型与计费时段，因此「钱花在哪了」与它上面的会话合计对得上。
- 所有数字都是依据 provider 上报的 token 用量得出的**估算值**，不是账单。价目表带抓取日期，发布前需对照官方
  定价页重新核对（见 `lib/cost-core/src/pricing.ts` 顶部注释）。

## 账号级用量（全设备）

上面的数字都来自本机的会话日志——账号在其他设备上的使用它们看不见，而账单是全账号汇总的。配置平台令牌后，
面板会多出「账号 · 全设备」区块：直接来自平台官方用量接口（`platform.deepseek.com/api/v0/usage/by_api_key/{amount,cost}`）
的今日已结算费用（北京时间，与账单同口径）、token 合计与数据时间戳。这些是平台的实际结算值，不是估算，且有结算
延迟——它与本机数字不一致是正常的，差额就是其他设备的花费。

配置方法：打开费用面板，「账号 · 全设备」区块会引导你完成——在任意已登录
<https://platform.deepseek.com/usage> 的设备上（DSH 所在机器本身不需要登录浏览器）执行面板里给出的控制台代码，
把结果粘贴进面板并保存。宿主会先用平台接口验证令牌，有效才写入 `$DSH_HOME/dsh-cost-platform-token`
（权限 `0600`；手动写该文件亦可，这也是无浏览器环境的宿主的配置方式）。该令牌是网页控制台的会话令牌——这些
接口不接受 `sk-` API Key——它只存在宿主机上，路由只回传统计数字与状态码。平台请求每五分钟最多一次且在后台
进行；刷新失败时保留最近一次数据并给出提示。

## 范围与限制

- **今日** 覆盖本机全部项目，并且包含已结束的会话。数据来自三处：进程内的 live 会话注册表（尚未落盘的轮次）；一组「交接中」的会话——注册表已经把它们
  移除，但存储是按 checkpoint 落盘的，磁盘日志可能滞后于会话结束一小时以上，这些会话在磁盘日志明确覆盖之前，会继续沿用 live 期间折叠出的结果；以及
  `$DSH_HOME/sessions` 下的持久化会话存储——按项目目录读取、解压、折叠，并按修改时间做缓存。自然日边界跟随你所在时区。
- 仅在浏览器里打开、宿主进程内已不 live 的会话，其「本会话」明细会返回 `not-live`；今日合计不受影响。
- 本版本读不了的会话日志会被**计数并展示**在面板页脚，不会静默跳过。
- 本机合计按官方价目估算，最终账单以 provider 的计费视图为准——账号级区块展示的正是这个视图。

## 路由

两个路由都是 DSH 宿主上的精确路径，并拒绝任何非 loopback 请求：

| 路由                                           | 返回                                                         |
| ---------------------------------------------- | ------------------------------------------------------------ |
| `GET /api/dsh-cost/summary?session=&tz=&lang=` | 会话、本轮与今日合计（含逐轮、逐模型与费用构成）及账号级区块 |
| `GET /api/dsh-cost/config`                     | 当前价目、计费时区与高峰时段                                 |

`currency=CNY|USD` 可按单次请求覆盖已配置的价目。
